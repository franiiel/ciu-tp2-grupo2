## Instalación y configuración

Cloná el repositorio:

```bash
git clone https://github.com/franiiel/ciu-tp2-grupo2.git
cd ciu-tp2-grupo2
```

Instalá las dependencias:

```bash
npm install
```

Iniciá el servidor de desarrollo:

```bash
npm run dev
```
